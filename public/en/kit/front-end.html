01 · 1The base

  1. 01 shadcn/ui ↗ Base components copied into your project, and the registry the collections below install through. ui.shadcn.comMIT (opens in a new tab)

02 · 5Component collections

  1. 02 React Bits ↗ Over two hundred animated text, background and interface components, in JS or TS, CSS or Tailwind. reactbits.devMIT + Commons Clause (opens in a new tab)
  2. 03 Skiper UI ↗ Scroll and cursor interactions: progress bars, text that reveals itself, stacks of cards. skiper-ui.comFree with attribution (opens in a new tab)
  3. 04 Componentry ↗ Editable source focused on scroll, kinetic typography and WebGL effects. componentry.devMIT (opens in a new tab)
  4. 05 KokonutUI ↗ Components for AI products: model selector, tool calls, citations, token alternatives. kokonutui.comMIT (opens in a new tab)
  5. 06 Bklit UI ↗ React charts on d3 and Motion, from area and bar charts to Sankey and choropleth maps. bklit.comMIT (opens in a new tab)

03 · 4Motion

  1. 07 GSAP ↗ Timelines and scroll-bound animation with ScrollTrigger. Entirely free, plugins included. gsap.comFree, own license (opens in a new tab)
  2. 08 Lenis ↗ Smooth scrolling that keeps the browser's own: sticky positioning and the scrollbar still work. lenis.devMIT (opens in a new tab)
  3. 09 Motion ↗ The former Framer Motion: enter, exit, layout and gestures driven by React state. motion.devMIT (opens in a new tab)
  4. 10 Anime.js ↗ A modular animation engine in plain JavaScript, for pages with no framework. animejs.comMIT (opens in a new tab)

04 · 1The third dimension

  1. 11 Three.js ↗ 3D in the browser with WebGL and WebGPU: glTF models, scenes, lighting and shaders. github.com/mrdoob/three.jsMIT (opens in a new tab)

05 · 3Skills for the agent

  1. 12 Impeccable ↗ A design vocabulary for the agent, with review, polish and a detector for generic interfaces. impeccable.styleApache 2.0 (opens in a new tab)
  2. 13 Taste Skill ↗ Art direction for an agent building a site from scratch, with references and an in-browser check. tasteskill.devMIT (opens in a new tab)
  3. 14 emilkowalski/skills ↗ Nineteen interface animation skills: build, review, remove and optimise motion. github.com/emilkowalski/skillsMIT (opens in a new tab)

06 · 2Brand research

  1. 15 research ↗ Matt Pocock's skill that investigates primary sources and saves a cited result in the repository. github.com/mattpocock/skillsMIT (opens in a new tab)
  2. 16 Firecrawl ↗ Reads sites for the agent and extracts the visual identity: palette, fonts, logo and screenshot. firecrawl.devAGPL-3.0 (opens in a new tab)

Install the skills

One paste in a terminal installs the five skills on the list into your coding agent. Each line asks which agent to install into.

npx skills@latest add pbakaus/impeccable
npx skills@latest add Leonxlnx/taste-skill
npx skills@latest add emilkowalski/skills
npx skills@latest add mattpocock/skills --skill research
npx skills@latest add firecrawl/skills

Import the bookmarks

  1. Chrome: bookmarks menu → Import bookmarks and settings → Bookmarks HTML file.
  2. Edge: Settings → Import browser data → Favorites or bookmarks HTML file.
  3. Firefox: Manage bookmarks → Import and Backup → Import Bookmarks from HTML.
  4. Safari: File → Import From → Bookmarks HTML File.
